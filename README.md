# Allen Christopher Raj D - Personal Portfolio

A GTA San Andreas pause-menu-styled portfolio for **Allen Christopher Raj D**, Aspiring AI Security Engineer & Ethical Hacker.

## 🚀 Features
- **Authentic GTA San Andreas Pause Menu Aesthetics**:
  - Muted sage-green and dark charcoal panels.
  - Authentic typography using **Diploma** (San Andreas logo font) and **Pricedown Black** (GTA franchise font).
  - Character portrait framed on the right with a custom San Andreas nameplate.
- **Fast & Interactive Sections**:
  - **About**: Profile dossier and background.
  - **Education**: Institutional records, scores, and coursework.
  - **Skills**: Combat/proficiency attribute bars.
  - **Projects (Missions)**: Mission cards featuring **SecureGuard** and **ARCShield** with "MISSION PASSED" stamps.
  - **Internship**: Professional experience at MindFul AI.
  - **Contact**: Direct links to Email, LinkedIn, and GitHub with official vector logos.
- **Navigation**:
  - Full keyboard navigation (<kbd>↑</kbd> / <kbd>↓</kbd> or <kbd>W</kbd> / <kbd>S</kbd> to select, <kbd>Enter</kbd> to confirm, <kbd>Esc</kbd> to return).
  - Mouse click and touch friendly.
  - Auto-loading progress intro screen.

## ⚙️ Content Management
All portfolio content (name, biography, education, skills, projects, and contact info) is easily updated directly inside [`portfolio-data.js`](portfolio-data.js) without needing to touch any HTML or CSS!

## 📦 Tech Stack
- Vanilla HTML5, CSS3, JavaScript (ES6)
- Webfont `@font-face` (Pricedown, Diploma, Beckett)
- Zero external dependencies
